Try the application locally

Clone the repository, use Python 3.10 or later, then run:

./helper test
./helper serve

Open http://127.0.0.1:8765. Offline simulation is explicitly labeled. Live Meta mode requires your private API key in a local .env file; never enter a key on this public page.

Prototype boundaries

Live Meta reasoning is integrated. Curb telemetry is a simulated fixture, and the 8 ft threshold is a demo fleet policy. Spoken requests are transcribed by Meta Muse Voice Transcribe through the console's server; appointment cards are read by Muse Spark. Both are verified live. SAM image measurement is not integrated. Demo acknowledgment does not authenticate a dispatcher or authorize a vehicle. No real dispatch, payments, clinical clearance or patient-record integration is performed.
